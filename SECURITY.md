# Security policy

NeuralKeep is an early-stage documentation and integration project, not a hardened product.

- Keep credentials and personal bookmarks out of Git.
- Restrict remote access to a trusted tailnet.
- Review upstream Karakeep security updates.
- Do not disable SSRF protection to crawl blocked or private addresses.
- Protect backups and persistent storage.
- Review logs and screenshots before sharing them.

For vulnerabilities in Karakeep or other upstream components, follow those projects' security disclosure policies. For issues specific to NeuralKeep's documentation, open an issue without posting secrets or exploit details.
